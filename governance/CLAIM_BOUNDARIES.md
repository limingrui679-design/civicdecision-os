# Claim boundaries

These boundaries apply to source code, documentation, demos, releases, CV/PS materials, and public posts.

| Evidence available | Safe description | Prohibited upgrade |
|---|---|---|
| Public dataset downloaded and validated | Public-data connector or case | Client project, proprietary data, government partnership |
| Deterministic tests pass | Tested implementation behavior | Real-world accuracy or policy effectiveness |
| Historical event replay | Offline historical replay/backtest | Live deployment or action taken at the time |
| Simulation output | Simulated result under named assumptions | Observed people helped, costs saved, or harm avoided |
| Optimization output | Model-recommended option | Adopted policy or operational decision |
| Public no-login demo | Publicly accessible demo | Production system or authenticated governance |
| External issue/comment/review | External feedback | Adoption, expert validation, or user impact unless independently established |

Every quantitative claim must resolve to a committed manifest, test/run artifact, release record, or external source. Unsupported claims remain `proposed`.
