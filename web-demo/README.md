# CivicDecision OS public walkthrough

This site is the public, read-only guided walkthrough for CivicDecision OS. It presents the
verified v0.8.0 repository snapshot, a completed and deliberately infeasible Suffolk heat-access
reference run, the evidence-type boundaries, and the local quickstart.

The page does not claim deployment, municipal adoption, external validation, policy validity, or
real-world impact. The full Evidence Explorer, API, SDK, CLI, artifact catalog, and reproducibility
checks remain in the parent repository.
